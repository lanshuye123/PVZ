# 01 · 项目概述

## 这是什么

**stabledecompile** 是《植物大战僵尸》一代（PopCap, 2009）的**社区反编译工程**。
它把原版游戏还原成可编译的 C++ 源码，让 mod 作者能直接修改游戏逻辑并重新构建，
而不是靠内存 hook 或注入。

工程同时支持两个版本分支：

| 分支 | 说明 |
|---|---|
| **GOTY** | 年度版（Steam App 3590）。有成就、Zombatar、新舞王僵尸等独占内容 |
| **OG / 2009** | 2009 原版。内容较少，但更贴近最初发行版 |

配套的编译配置、运行时依赖和资源目录都随分支切换，见 [02-开发参考](02-开发参考.md)。

## 能做什么

工程在原版基础上已经做了大量扩展（引自仓库根 `README.md`，并按当前代码校正）：

**已完成**

- 同时支持 **x86 (Win32)** 与 **x64** 构建
- 同时支持 **GOTY** 与 **OG(2009)** 构建
- **用 SDL3 替换了原版的 DirectDraw / DirectX 7 图形后端**，以便在现代系统上运行
- 用 **FFmpeg** 实现视频播放
- 移植了 **成就系统** 与 **Zombatar**
- 用 **PortAudio** 实现麦克风输入
- **多 PAK 文件支持**（`main.pak` 之外可叠加资源包）
- 恢复并补完了一批被废弃的内容
- 加入屏保模式
- 修复了原版的若干 bug
- 通过 `GameConstants.h` 的开关启用：移动版小游戏、Last Stand 内容、
  Bloom & Doom 内容（默认关闭）、若干 QoL 与平衡性选项

**计划中**

- 粒子编辑器（进行中）
- 主机版小游戏与 PvP 内容
- 字体生成器
- 宽高比切换 / 宽屏支持
- 更多设置界面
- 多语言 Unicode 支持

## 技术栈现状

原版引擎是 PopCap 的 **SexyAppFramework** + DirectDraw 7。本工程保留了框架的整体
结构（`Graphics` / `Widget` / `Image` / `ResourceManager` 等接口不变），但把**渲染后端
换成了 SDL3**，因此：

| 能力 | 当前实现 | 关键位置 |
|---|---|---|
| 窗口与渲染 | SDL3 | `LawnApp.cpp` (`SDL_CreateWindow` / `SDL_CreateRenderer`) |
| 字体 | SDL3_ttf | `SexyAppFramework/SDL3Font.cpp` |
| 贴图 | SDL3 texture（`ARGB8888`，`TARGET`） | `SexyAppFramework/SDL3Image.cpp` |
| 视频 | FFmpeg（`avcodec` / `avformat` / `avutil`） | `include/ffmpeg` |
| 音频 | BASS（音乐/音效）+ PortAudio（麦克风） | `SexyAppFramework/BassLoader.cpp` |
| 文件对话框 | tinyfiledialogs | `include/tinyfiledialogs` |
| 压缩 | zlib（**静态链接**） | `include/zlib` |
| 调试 UI | Dear ImGui | `include/imgui` |

> 注意：`BassLoader.cpp` / `BassMusicInterface.cpp` 在项目里被显式排除编译
> （`ExcludedFromBuild`），但 `bass.lib` 仍在链接列表里。

## 环境要求

| 项 | 要求 | 备注 |
|---|---|---|
| 编译器 | **Visual Studio 2022** + C++ 桌面开发工作负载 | 项目使用 v143 工具集 |
| C++ 标准 | **C++20**（`stdcpp20`） | |
| Windows SDK | 10.0.22621 或 10.0.26100 **（已验证）** | 项目声明 `WindowsTargetPlatformVersion=10.0` |
| 游戏资源 | **你合法拥有的** PvZ（GOTY 或 2009） | 见下方免责声明 |
| 磁盘 | 约 2 GB | 输出目录含 ~350 MB 运行时 DLL |

## 目录结构

```
stabledecompile/
├── LawnApp.cpp / .h        游戏主类（初始化、场景切换、对话框，约 4900 行）
├── main.cpp                WinMain 入口
├── GameConstants.h         棋盘尺寸等常量 + 功能开关
├── ConstEnums.h            全局枚举（由 Resources 生成器产出）
├── Resources.cpp / .h      自动生成的资源 ID 表（约 176 KB / 118 KB）
├── PlantsVsZombies.sln     解决方案
│
├── Lawn/                   游戏逻辑（PvZ 本体）
│   ├── Board / Plant / Zombie / Projectile / Challenge / Coin / ...
│   ├── System/             存档、玩家信息、音乐、数据同步
│   └── Widget/             各界面（主菜单、图鉴、商店、Zombatar...）
├── Sexy.TodLib/            动画、粒子、特效、字符串表（PopCap TodLib）
├── SexyAppFramework/       引擎层（原 PopCap SexyAppFramework + SDL3 后端）
├── PakLib/                 PAK 资源包读写（PakInterface）
├── Editor/                 粒子编辑器界面
├── assets/                 随游戏分发的文件，构建时整体复制到输出目录
├── bin/x86, bin/x64/       运行时 DLL（由 Git LFS 管理）
├── lib/                    第三方库导入库 / 静态库
├── include/                第三方库头文件（imgui, sdl3, ffmpeg, zlib, bass, ...）
├── tools/                  PopCap 官方工具（PopPak, ResourceGen, FontBuilder, 文档）
└── build/                  构建输出（.gitignore 忽略）
```

**代码分层**（从上到下依赖）：

```
Lawn / Editor          ← 游戏业务逻辑
      ↓
Sexy.TodLib            ← 动画与特效
      ↓
SexyAppFramework       ← 引擎（窗口、图形、音频、输入、资源、Widget）
      ↓
PakLib                 ← 资源包读取
      ↓
include/ (SDL3, FFmpeg, zlib, ...)
```

## 免责声明

工程**不包含**任何 PopCap 的知识产权内容（不含美术、音频、`.pak` 资源），
只输出反编译后的可执行文件。要运行它，你必须：

- 编译 **GOTY** 配置 → 需要合法拥有 [Steam 上的 PvZ: GOTY Edition](https://store.steampowered.com/app/3590/)
- 编译 **2009** 配置 → 需要合法拥有 2009 原版

本工程不鼓励盗版。

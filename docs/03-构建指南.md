# 03 · 构建指南（User Guide）

从零开始把这个工程编译成可运行的游戏。全部步骤 **（已验证）**。

## 前置要求

| 项 | 说明 |
|---|---|
| **Visual Studio 2022** | 安装时必须勾选 **"使用 C++ 的桌面开发"** 工作负载 |
| **Windows SDK** | 随工作负载安装（10.0.22621 或 10.0.26100 均可） |
| **Git + Git LFS** | `bin/` 下的运行时 DLL 由 LFS 管理 |
| **正版游戏** | GOTY 版（Steam App 3590）或 2009 原版 |
| **磁盘空间** | 约 2 GB（输出目录含 ~350 MB 运行时 DLL） |

检查工具链是否齐备：

```powershell
$vs = "D:\Program Files\Microsoft Visual Studio\2022\Community"
Test-Path "$vs\MSBuild\Current\Bin\MSBuild.exe"   # 应为 True
Get-ChildItem "$vs\VC\Tools\MSVC"                 # 应有 14.4x 版本目录
Get-ChildItem "C:\Program Files (x86)\Windows Kits\10\Include"  # 应有 10.0.xxxxx.0
```

## 第 1 步：获取源码（别忘了 LFS）

```powershell
git clone https://github.com/<你的用户名>/PVZ.git
cd PVZ
git lfs pull
```

**`git lfs pull` 不能跳过。** 如果没执行（或中途失败），`bin/x64` 和 `bin/x86`
下的 DLL 会缺失或只剩几十字节的指针文件，构建能过但**游戏无法启动**。

校验 LFS 是否完整：

```powershell
# 24 个对象，全部应显示 *（已下载），没有 -（缺失）
git lfs ls-files
```

## 第 2 步：放置游戏资源

把**你合法拥有的**游戏目录整个复制到仓库根目录，并**重命名**为下列之一：

```
Plants Vs Zombies/      ← 优先匹配这个
Plants Vs. Zombies/     ← 或这个（带点）
```

两个名字都是构建脚本认可的。目录里必须包含：

```
main.pak                    ← 45 MB 左右
properties/                 ← default.xml, Layout.xml, partner.xml, ...
```

> **Steam 版注意**：Steam 的 PvZ 目录里可能有个启动器，真正的游戏文件在子目录里，
> 要复制的是含 `main.pak` 的那一层。

> **这个目录会被 `.gitignore` 忽略**（`Plants Vs. Zombies/*`），不会误提交。

### 确认你的版本（GOTY 还是 2009）

选错配置会导致内容缺失或崩溃。一个可靠的判据：把游戏自带的
`PlantsVsZombies.exe` 与仓库根目录的参考 exe 比对哈希。

```powershell
$a = (Get-FileHash "Plants Vs. Zombies\PlantsVsZombies.exe" -Algorithm SHA256).Hash
$b = (Get-FileHash "PlantsVsZombies.exe" -Algorithm SHA256).Hash
if ($a -eq $b) { "GOTY（与参考 exe 一致）" } else { "不是 GOTY，或版本不同" }
```

GOTY 参考哈希：`868F8E2BAB0D6A7EF8AFC4C5960C608ECCEF82BD086BD6E0C0E2670199A5CA45`

## 第 3 步：选择配置

| 你的版本 | 开发用 | 发布用 |
|---|---|---|
| **GOTY**（Steam 年度版） | `DebugGOTY` | `ReleaseGOTY` |
| **2009 原版** | `Debug` | `Release` |

平台选 `x64`（现代机器）或 `Win32`（兼容旧机器）。

> ⚠️ **x64 上无法构建真正的 2009 版** —— 四个 x64 配置都定义了 `_GOTY`。
> 需要 2009 行为请用 **Win32**。详见 [02-开发参考 §1](02-开发参考.md#1-构建配置矩阵)。

> ⚠️ 首次接触本工程建议先用 `DebugGOTY|x64`，它会输出控制台和更多调试信息。

## 第 4 步：构建

### 方式 A：Visual Studio

打开 `PlantsVsZombies.sln`，在工具栏选好 `配置 | 平台`，按 **F6** 构建
（或 **F5** 构建并直接启动）。

### 方式 B：命令行（推荐用于自动化）

```powershell
$msbuild = "D:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe"

& $msbuild PlantsVsZombies.sln `
    /p:Configuration=ReleaseGOTY /p:Platform=x64 `
    /m /nologo /v:minimal
```

加日志便于排查：

```powershell
& $msbuild PlantsVsZombies.sln /p:Configuration=ReleaseGOTY /p:Platform=x64 /m `
    "/flp:logfile=build.log;verbosity=normal"
```

**成功的标志**：结尾出现 `已成功生成。` / `Build succeeded.`，`0 个错误`。
构建产物约 7.7 MB，全程约 3 分钟（首次全量编译）。

> 构建前请**关闭正在运行的游戏**，否则链接会报
> `LNK1168: 无法打开 ...PlantsVsZombies.exe 进行写入`。

## 第 5 步：运行

```powershell
.\build\ReleaseGOTY_x64\bin\PlantsVsZombies.exe
```

首次运行会要求你新建一个玩家档案。存档位置默认是
`%APPDATA%\PopCap Games\PlantsVsZombies\userdata\`，
可用 `savedata.ini` 改成便携/实例/自定义路径 —— 见 [04-存档配置](04-存档配置.md)。

## 构建产物说明

输出目录：`build\<Configuration>_<Platform>\`

```
build/ReleaseGOTY_x64/
├── bin/                    ← 实际运行目录
│   ├── PlantsVsZombies.exe     构建产物
│   ├── PlantsVsZombies.pdb     调试符号
│   ├── main.pak                从游戏目录复制
│   ├── dependency.pak          从 assets/ 复制
│   ├── properties/             从游戏目录的 properties/ 复制
│   ├── extension/              从 assets/ 复制
│   ├── videos/                 从 assets/ 复制（intro.mp4）
│   ├── savedata.ini            从 assets/ 复制（存档位置配置）
│   ├── SDL3.dll, SDL3_ttf.dll, bass.dll, zlib1.dll ...
│   ├── avcodec-62.dll, avformat-62.dll, avutil-60.dll ...   FFmpeg
│   ├── portaudio_x64.dll, tinyfiledialogs64.dll
│   └── *.bat                   粒子编辑器 / 屏保启动脚本
└── obj/                    ← 构建缓存，可安全删除
```

`bin/` 里的东西由 **PostBuildEvent** 自动准备，无需手工复制：

```bat
robocopy "$(SolutionDir)assets"        "...\bin"              /S
robocopy "$(SolutionDir)bin\x64"       "...\bin" *.dll /S
robocopy "%PVZ_DIR%"                   "...\bin" *.pak  /S
robocopy "%PVZ_DIR%\properties"        "...\bin\properties"  /S
```

（`%PVZ_DIR%` 依次尝试 `Plants Vs Zombies` 和 `Plants Vs. Zombies`。）

> **改了 `assets/` 里的文件** → 下次构建会自动同步到输出目录。
> **删了 `assets/` 里的文件** → 输出目录里的同名文件**不会**被删除，
> 需要手工清理或删除整个 `build\<...>\bin\` 后重建。

## 运行时依赖检查

如果游戏起不来，先确认 exe 的直接依赖都在 `bin/` 里：

```powershell
$dumpbin = "D:\Program Files\Microsoft Visual Studio\2022\Community\VC\Tools\MSVC\14.44.35207\bin\Hostx64\x64\dumpbin.exe"
& $dumpbin /dependents .\build\ReleaseGOTY_x64\bin\PlantsVsZombies.exe
```

需要自带的非系统 DLL：

| DLL | 来源 |
|---|---|
| `SDL3.dll`, `SDL3_ttf.dll` | `bin\x64\`（LFS） |
| `avcodec-62.dll`, `avformat-62.dll`, `avutil-60.dll` | `bin\x64\`（LFS） |
| `portaudio_x64.dll` | `bin\x64\`（LFS） |
| `tinyfiledialogs64.dll` | `bin\x64\`（LFS） |
| `zlib1.dll` | `assets\`（随仓库分发） |
| `bass.dll` | `bin\x64\`（LFS） |

> `avfilter-11` / `swresample-6` / `swscale-9` / `avdevice-62` **不是** exe 的直接导入，
> 但会被上面几个 FFmpeg DLL 间接依赖，PostBuild 会一并复制。

- [ ] 该目录里有 `main.pak` 和 `properties\`
- [ ] 已确认版本（GOTY / 2009），并选了对应配置

- [ ] `bin\` 下能看到 SDL3.dll 等运行时 DLL
